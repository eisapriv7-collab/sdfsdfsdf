How it works

Twelve fixed strategy families examine trend, momentum, mean reversion, volatility, channels, support/resistance, candle anatomy and multi-horizon behavior. Their weighted score is converted into an empirical probability using similar earlier setups from the loaded history.

Validation

The displayed paper metrics are produced chronologically. Each historical probability uses only setups that came before it. Ties are treated as refunds. Payout-adjusted returns use a fixed one-unit stake and never use Martingale.

Limits

This file uses Deriv's public EUR/USD feed. It does not know Quotex's private quote, payout changes, settlement latency, OTC prices, news that has not occurred, or orders that have not reached the market. A different broker can close the same five-minute period at a different price.

No model can confirm a sure shot. The correct output is often NO TRADE. Historical behavior can change immediately.
